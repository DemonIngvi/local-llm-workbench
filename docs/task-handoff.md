# Прототип общего реестра задач

`scripts/tasks.py` хранит задачу и журнал передачи в локальной SQLite-базе `data/tasks.sqlite3`. Это отдельный подготовительный этап: он **не запускает harness**, не соединён с LibreChat и не контролирует процессы, работающие в обход реестра. Не считайте его песочницей или полноценным механизмом безопасности.

Примеры для Windows (`python`; на Linux используйте `python3`). Сначала создайте существующий отдельный каталог workspace:

```powershell
python scripts/tasks.py create --title "Исправить тесты" --workspace D:\my-workspace --harness opencode
python scripts/tasks.py show TASK_ID
python scripts/tasks.py acquire TASK_ID --harness opencode
# Сохраните выданный токен приватно; он необходим для освобождения.
python scripts/tasks.py release TASK_ID --token TOKEN --summary "Что сделано и что осталось"
python scripts/tasks.py handoff TASK_ID --to deepseek --summary "Что нужно продолжить" --confirm
python scripts/tasks.py show TASK_ID
```

`acquire` атомарно резервирует задачу и точный канонический путь workspace в этой базе; второй управляемый запуск для того же пути запрещён. `release` проверяет токен и записывает результат; `handoff` разрешён только после освобождения и явного `--confirm`. События и последняя сводка сохраняются, но содержимое файлов и внутренние сессии harness не копируются. Каталог не монтируется и не передаётся агенту автоматически.

Ограничения: блокировка действует **только среди клиентов этой базы, соблюдающих протокол**, не защищает от ручной записи, разных баз, разных ОС/WSL-представлений одного пути, bind mounts, жёстких ссылок или вложенных директорий. Будущий orchestrator должен устранять эти коллизии, самостоятельно удерживать токен и запрещать запуск вне своего контроля. После аварии блокировка остаётся: восстановление/проверка остановки процесса и безопасное административное снятие пока не реализованы; не редактируйте базу во время работы. Секретный токен может попасть в историю оболочки и список процессов — ручной CLI предназначен лишь для разработки. База содержит пути и описания задач; ограничьте к ней доступ и делайте резервную копию при остановленных клиентах.
