- E1 S1.1–S1.2: прототип; требуется проверка на обеих ОС.
- E1 S1.3: конфигурация создана, E2E не подтверждён.
- E2 S2.1: исследованы публичные API, подготовлены конфигурация OpenCode V2 через LiteLLM и экспериментальный HTTP-клиент; нет проверки фиксированной версии и end-to-end; в работе.

- E3 S3.2: 16 unit-тестов пройдены в Windows и WSL, включая mock HTTP API OpenCode и machine state. Ранее прошёл изолированный Docker smoke-тест LiteLLM с фиктивным сервером. Полный E2E с LibreChat/LM Studio не выполнен.
- E3 S3.3: отдельные ключи LiteLLM генерируются; квоты требуют базы данных.
