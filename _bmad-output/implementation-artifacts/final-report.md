## Критические ограничения

### DeepSeek SDK
Официальный `sdk-minimal` использует `danger-full-access`:
- Агент может модифицировать любой файл
- Агент может выполнять любые команды
- События журнала отправляются в DeepSeek

**Нельзя подключать к пользовательским файлам как к песочнице.**

### LibreChat интеграция
Custom endpoint LibreChat — это OpenAI-совместимый API, не универсальный протокол запуска агента. Реальный запуск harness через LibreChat не подтверждён документацией.

### Версии образов
Используются плавающие теги (`latest`, `main-stable`). Для production требуются фиксированные digest.

### Квоты LiteLLM
Отдельные ключи генерируются, но без базы данных LiteLLM они не ограничены.

## Что необходимо для production

1. **Фиксация версий** всех образов (digest или exact tag)
2. **Настройка базы данных** LiteLLM с квотами и ограничением моделей
3. **Разработка изолированного профиля** DeepSeek без `danger-full-access`
4. **Integration-тесты** с реальным LM Studio и LibreChat
5. **Ревью политики разрешений** OpenCode перед запуском реальных задач
6. **Мониторинг и аудит** выполнения задач
